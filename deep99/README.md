# 행성에서의 99일 (DEEP-99)

불시착한 조종사가 **99일 안에** 탈출선을 재조립하고 실종된 승무원 넷을 구출하는
탑다운 생존 로그라이크. 기획서 v2 를 그대로 구현했습니다.

**플레이:** https://yeonny3209.github.io/qkrtpdbs1/deep99/

---

## 이 게임의 심장 — 캠프파이어

모든 것이 불 하나에 매달려 있습니다.

| 불이 하는 일 | 결과 |
|---|---|
| **개방 반경** | 갈 수 있는 거리가 정해집니다. Lv1 은 25타일, Lv6 이면 맵 전체 |
| **안전 반경** | 이 안에서는 산소가 차고 짐승이 물지 않습니다 |
| **연료 해금** | Lv2 에 닿아야 기름 통이, Lv3 에 닿아야 가스 통이 보입니다 |
| **몹 등급** | 불을 키운 만큼 바깥의 것들도 세집니다 |
| **꺼지면** | 거미가 굶주립니다 — 두 배로 빨라지고, **안전 반경 안까지 들어옵니다** |

개방 반경은 **도달한 최고 레벨**로, 안전 반경은 **지금 레벨**로 정해집니다.
불이 꺼졌다고 지도 밖으로 튕겨 나가 죽는 일은 없습니다.

## 5분 안에 알아야 할 것

- `WASD` 이동 · `Shift` 달리기(배고픔 3배) · `E` 상호작용 · `Tab` 가방
- 나무를 베어 **통나무를 불에 넣으세요.** 1일차는 튜토리얼이라 안 죽습니다
- 밤에는 거미가 옵니다. **손전등을 거미에게 비추면** 굳습니다
- 캠프 밖에서 산소가 떨어지면 우주복이 깎이고, 우주복이 0 이면 죽습니다
- 죽어도 **블랙박스 데이터**가 남아 다음 런의 직책·시작 장비가 열립니다

## 구조

```
src/
  core/       RNG(시드 분리) · GameState · Loop(고정 60fps) · Input · Audio · SaveData
  data/       *.json — 숫자는 전부 여기. 코드에 상수를 안 적었습니다
  world/      Tilemap · MapGen · Spawner · FogOfWar · ZoneGate(에너지 장벽)
  systems/    Campfire · Time · Survival · Weather · Decay · Combat
              Inventory · Crafting · Lab · Raid · Run
  entities/   Player · Spider · Animal · Raider · Crew · Projectile
  minigame/   AsteroidDodge · Salvage
  render/     Camera · Lighting · Effects · Renderer   (Canvas 2D)
  ui/         HUD · Inventory · Lobby · Cutscene · DeathScreen   (DOM)
```

`core` · `data` · `world` · `systems` · `entities` · `minigame` 은 **DOM 도 캔버스도
모릅니다.** 그래서 브라우저 없이 Node 에서 그대로 돌려 잽니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5250
npm run check    # 린트 + 타입 + 로직 시험 + 그리기 시험
npm run build
```

### 시험

| 명령 | 내용 |
|---|---|
| `npm test` | 순수 로직 **44,901** 개 단언 — 균형 수치까지 실측합니다 |
| `npm run test:render` | linkedom + 기록용 캔버스로 그리기·UI **97** 개 단언 |

로직 시험은 통과/실패만 보지 않고 숫자를 찍습니다 — 맵에 통나무가 몇 개
깔리는지, Lv6 불이 가스 통 다섯 개로 몇 초 가는지, 한 런에 블랙박스가 얼마나
나오는지. 기획서 §부록B 가 검증하라고 지목한 것들입니다.

### 변이 시험

구현을 92곳 일부러 망가뜨려 시험이 잡는지 봤습니다. **91건 잡음.**
남은 하나는 등가 변이입니다 — 문턱 아래 잔불을 0 으로 지운 뒤라
`heat <= 0` 과 `level <= 0` 이 같은 뜻이 되었습니다.

그 과정에서 찾아 고친 진짜 버그들:

- **문턱 아래 잔불이 갇혔습니다.** 화력이 0.7 이면 레벨은 0, 레벨이 0 이면
  소모도 0 — 영영 안 줄고 "꺼졌다"로도 안 읽혔습니다. 안전 반경은 0 인데
  거미는 안 굶주리는 어긋난 상태였습니다
- **시체에서 전리품이 복사됐습니다.** 죽은 약탈자를 터렛이 계속 때리면
  프레임마다 고철이 새로 떨어졌습니다
- **잔해 채취가 무한 고철이었습니다.** 성공에 쉬는 시간이 없어 분당 312개가
  나왔습니다(§7.4 목표는 40~50). 재 보고 알았습니다
- **창을 열어 둔 채 죽으면** 다음 런이 화면에 아무것도 없는데 안 움직였습니다
- **HUD 에 마감일이 없었습니다.** §19.2 는 `DAY 041 / 99` 인데 `DAY 041` 만
  나와, 99일이라는 이 게임의 전제가 화면 어디에도 없었습니다

## 기획서 대비

기획서 §1~§21 을 전부 구현했습니다. 벗어난 곳은 셋입니다.

1. **Howler 대신 Web Audio 직접** — 음원 파일이 하나도 없고(전부 합성)
   필요한 것이 공간 오디오와 로우패스뿐이라 로더가 할 일이 없었습니다
2. **지형을 저장하지 않습니다** — 지대가 중심에서의 거리로 정해지므로
   함수 하나면 됩니다. 240×240 배열을 들고 다닐 이유가 없었습니다
3. **대원 로한의 연료 자동 투입에 제한** — §부록B-4 가 직접 의심한 부분입니다.
   저장고에 연료가 있을 때만 넣습니다. 압박이 사라지는 게 아니라
   "연료를 모으는 일"로 옮겨 갑니다
